# Resume

Igor Souza's resume, extracted from the [portfolio site](https://github.com/igormcsouza/igormcsouza.github.io). Deployed via GitHub Pages at https://igormcsouza.github.io/resume.

## Development

```bash
docker compose up --build
```

Then open http://localhost:12001/en/.

Without Docker:

```bash
npm install
npm run dev
```
